# Procédures

Fiches à imprimer pour l'équipe, une par situation. Elles décrivent l'application telle qu'elle est ; si un écran change, mettez la fiche à jour dans la même pull request.

| Fiche | Pour qui | Quand |
| --- | --- | --- |
| [Bénévoles](benevoles.md) | Tous les bénévoles, sans connaissance technique | Installation, pendant le service, fin de soirée (une page) |
| [Livreur](livreur.md) | Bénévoles qui apportent les plats aux tables | Service à table (Loto), demi-page |
| [Jour J](jour-j.md) | Responsable de l'événement | Veille, installation, pendant le service |
| [Coupure réseau](coupure-reseau.md) | Caisses, cuisine, comptoir | Dès que le réseau tombe |
| [Clôture](cloture.md) | Responsable de l'événement, trésorier ou trésorière | Fin du service |
| [Incidents](incidents.md) | Responsable de l'événement | Tablette en panne ou perdue, mot de passe oublié… |

Les commandes du serveur (`php bin/console …`) se lancent en SSH sur l'hébergement, dans le dossier du projet (pas à pas pour notre serveur : `docs/hebergement.md`, dont la section 7, « Vérifications avant un événement »).

À tester pendant la répétition générale : toute la fiche « Jour J », et l'exercice de la fiche « Coupure réseau ».
