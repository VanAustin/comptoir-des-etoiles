# Signaler une faille de sécurité

Merci de prendre le temps de signaler un problème de sécurité.

**Ne créez pas de ticket public (issue)** pour une faille : elle serait visible de tous avant d'être corrigée.

## Comment signaler

Utilisez le signalement privé de GitHub :

1. Ouvrez l'onglet **Security** du dépôt.
2. Cliquez sur **Report a vulnerability**.
3. Décrivez le problème : ce qui est touché, comment le reproduire, et ce qu'une personne malveillante pourrait en faire.

Seule la personne qui maintient le projet voit votre signalement.

## Ce qui se passe ensuite

- Vous recevez une réponse sous 7 jours.
- La faille est corrigée en priorité, puis une nouvelle version est publiée.
- Si vous le souhaitez, votre nom est cité dans la note de version.

## Versions concernées

Seule la dernière version publiée reçoit les correctifs de sécurité.
